# 📘 Assignment: Games in Python

## 🎯 Objective

Build a playable Hangman game in Python to practice strings, lists, loops, conditionals, user input, and random selection.

## 📝 Tasks

### 🛠️ Set Up the Game

#### Description

Complete the initial game setup by selecting a secret word and creating variables to track the player's progress.

#### Requirements

Completed program should:

- Randomly select a secret word from the provided list.
- Initialize a collection for the player's guessed letters.
- Track the number of incorrect guesses.
- Set a maximum number of incorrect guesses.

### 🛠️ Build the Hangman Game Loop

#### Description

Create the game loop that accepts guesses, displays progress, updates the game state, and ends with an appropriate result.

#### Requirements

Completed program should:

- Display the hidden word as underscores and reveal correctly guessed letters.
- Ask the player for a letter guess and process the input.
- Track incorrect guesses and show how many attempts remain.
- End when the player guesses the word or reaches the maximum number of incorrect guesses.
- Display a clear win or lose message.
